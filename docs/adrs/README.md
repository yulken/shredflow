# Decision records

Architecture Decision Records (ADRs) for the app in this workspace:
`shredlog-project/shredlog`, which ships under the brand `GuitarTrain`
(`app_brand` in `src/lib/locales/*.ts`) and stores its data in the Supabase
tables `exercises` and `practice_sessions`.

These were written on 2026-10-27, largely after the fact. Each record states the
context that was in play, the decision that was taken, the alternatives that were
rejected, and the consequences. Read them as a written baseline: argue changes
against these, not against conversation memory.

## Status vocabulary

- **Accepted** - the decision is in force and is implemented in the tree.
- **Provisional** - the decision is in force, but its output is interim and still
  needs human review before it can be called final.
- **Superseded** - replaced by a later record; the header names the replacement.

## State of the tree when these were written

- One commit (`initial commit`) plus uncommitted work: `App.tsx`,
  `ExerciseList.tsx`, `SessionView.tsx`, `ThemeToggle.tsx` are modified;
  `src/lib/i18n.ts`, `src/lib/locales/*`, `src/hooks/useLanguage.ts` and
  `src/components/LanguageToggle.tsx` are new and untracked. Nothing is pushed.
- `npm run typecheck` and `npm run build` both pass (1641 modules, `dist/` is
  git-ignored).
- `src/lib/locales/en.ts` is the only hand-authored and reviewed dictionary. The other two are
  machine output and interim, which is what ADR-0015 states and lists:
  - `es.ts` is a stale partial mirror: 54 of its 63 values are byte-identical to EN, `nativeName`
    is `'Espa\u00fcl'` (an `u00fc` where `u00f1` belongs) and its `categories` list still
    holds three EN fallbacks (`Speed`, `Warm-up`, `Study`). It must be regenerated by the
    generator in ADR-0013.
  - `pt.ts` is harvested from the pre-migration component sources and accent-folded, so it
    reads `exercicio`, `treinos` and `Gerencie` with no accents at all. Its own defects are
    `nativeName: 'Portugus'`, `no_exercises_title: 'Nenhum exercicio ainda'`,
    `comecar` in `no_exercises_text` and `tension_medium: 'Moderada'`.
- Open item in the ES layer: `LITERAL` in `gen-es.mjs` pins the three tension labels and
  `save_button`/`history_title`/`exercises_title` to their English wording, while the machine
  had proposed `Bajo`/`Medio`/`Alto` for the tiers. ES is therefore English chrome by
  override, which stops the machine from producing worse words but is not a decision about
  Spanish. Settling that vocabulary is the next record, not an edit to these files.
